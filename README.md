# 🚀 SAP CAPM Practice

This repository contains my hands-on practice and learning journey with
**SAP Cloud Application Programming Model (CAPM)**.

I am learning SAP CAPM step by step using **SAP Business Application Studio (BAS)**.

The purpose of this repository is to practice CAPM concepts by creating
small projects, testing APIs, understanding errors, and documenting what
I learn.
